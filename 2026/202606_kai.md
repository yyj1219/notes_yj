# 프로젝트 정보

## 프로젝트 설명

- S/4HANA 1610 -- S/4HANA 2023 Upgrade
- GPD(Grouping, Pegging, Distribution) --> PMMO(Project Manufacturing Management and Optimization) Upgrade
- Dassian Solution(ABAP으로 개발된 미국방 관련 솔루션) 제거
- Dassian 제거와 GPD --> PMMO 전환에 따른 결산 프로세스 재 정립

## 프로젝트 환경

- 인터넷 사용 불가
- On-Premise 시스템
- SAP GUI 사용 가능: DBACOCKPIT(구 ST04)만 사용할 수 있을 것 같음.
- HANA Studio 사용 여부 알 수 없음
- 진단용 트레이스 활성화는 가능
- 그 외 기본은 read-only 작업만 가능
- Expensive Statements Trace 활성화 가능 여부 알 수 없음 (가능할 확률 높음)

## 요청 사항

- 결산 관련 프로그램 성능 및 결산 데이터 건수 최적화 작업
- S/4HANA 2023 최적화 작업 및 프로그램 튜닝

## SAP HANA DB 진단과 성능 최적화 업무 요청 사항

- 고비용 SQL 실행계획(Plan) 분석
- 인덱스, Full Scan, 조인 점검
- Delta Merge 연계 확인
- SQL(DB) 개선 포인트  정의
- HANA DB Parameter 점검
- Top N SQL 분석 (Optional)
- OOM(Out of Memory) 점검 (Optional)

## 총 기간 (5 영업일)
- 1일차: 착수 및 환경/자료 수집
- 2~5일차: 
    - 인프라 아키텍처 검토 및 서버 자원 부하 추이 분석
    - S/4HANA 구성 현황 점검 및 Basis 영역 점검
    - HANA 구성 현황 점검 및 결산 프로그램 성능 진단
    - 결산 프로그램 성능 진단
